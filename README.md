# Code

** This project is based on ElectroSmash's Arduino UNO Shield, all credit and 
similarities goes to them: https://www.electrosmash.com/pedalshield-uno **

My code here didn't really change much from ElectroSmash's code except that I added the OLED code to display the name of the current effect. The UNO REV 3 has two sets of SCL and SDA pins so I figured that I could add this addition to the overall project as a quality of life improvement. In a future revision I would like to perhaps do a small animation that reflects the effect or somehow have it fit onto the PCB itself using SMD parts that are usually smaller.
