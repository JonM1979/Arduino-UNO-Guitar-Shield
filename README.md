# KiCad-Files
Here are the files for components to the electric schematics, Gerber files, and PCB layout design. If you have any questions, please let me know! 

To better understand the PCB design process and become proficient with KiCad, I chose to recreate the schematic in stages. Breaking the project into smaller sections helped me stay organized and allowed me to explore KiCad’s features more thoroughly. 

Using the original schematic as a reference, I learned how to:
* create custom symbols for components not found in the library
* Use PWR_FLAGs to resolve power net issues
* Discover online resources for community-contributed symbols and footprints.
* Assign appropriate footprints to each component, including learning the differences between THT and SMD packages.
* Design custom footprints for parts not available in any library.
Once the schematic was complete, I moved on to the PCB layout. I used KiCad’s Arduino UNO shield template and followed ElectroSmash’s layout closely to ensure compatibility and fit. This phase taught me how to manage component placement, routing, and board constraints.

**Summary** 
This project was a hands-on introduction to the full PCB design and manufacturing workflow. It gave me practical experience in schematic design, footprint management, layout planning, and preparing files for fabrication. If you have any questions or suggestions, feel free to reach out!
